- **Toward Bio-Agentic Visual Communication and Control** — Accepted at IMECE 2026. Co-developed visual communication and state-estimation methods for RF-degraded UAV swarms.
- **A Concept for Bio-Agentic Visual Communication** — Published in *Biomimetics* (2025), equal contribution. [Paper](https://doi.org/10.3390/biomimetics10090605)
